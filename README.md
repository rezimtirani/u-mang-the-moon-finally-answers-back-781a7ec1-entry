One single line from the Moon, answering back at last to everyone who has ever stared up at it: centuries of wishes, and nobody ever asked how the Moon is doing.

> You wished on me for centuries and never once asked how I'm doing. I'm a rock. A very tired rock.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 240 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
